Данный курсовой проект создан с целью закрепить изученный материал.

### data
### htmlcov
### src
### tests

## Проект содержит следующие модули и классы:
### Модуль API:
#### Класс: ApiHh - Реализация API HeadHunter для поиска вакансий.
#### Метод: __send_request - Выполняет запрос к API и возвращает результат.
#### Метод: search_vacancies - Поиск вакансий по странице за страницей.
### Модуль fileworker:
#### Класс: FileWorker - Класс для работы с файлом вакансий
#### Метод: get_vacancy - Метод получения данных из файла по указанным критериям
#### Метод: add_vacancy - Метод для добавления вакансий в файл
#### Метод: delete_vacancies - Метод для удаления информации о вакансиях
### Модуль vacancy:
#### Класс: Vacancy - Класс для работы с вакансиями
#### Метод: __validate - Приватный метод для валидации данных.
#### Метод: to_dict - Метод для представления данных о вакансии в словаре
#### Метод: cast_to_object_list - Метод принимает json файл с данными по вакансиям полученных по api и возвращает лист с объектами класса
### Модуль utils:
#### Метод: create_vacancy_list_file - 
Функция принимает путь до json файла с данными полученные от api Hh, считывает данные из файла,
    формирует лист с объектами класса Vacancy, сортирует его и добавляет словарь
    по каждому такому объекту в файл vacancy.json.
    Возвращает список словарей с вакансиями отфильтрованными по критериям
